# Android 1.1.8 (10108): совместимость VPN-подключения

## Изменение

Для TLS при загрузке конфигурации и подключении WebSocket явно выбираются
классические группы обмена ключами. Это исключает большой гибридный ML-KEM
ClientHello, который может зависать на несовместимом сетевом маршруте.
TLS 1.2/1.3, проверка цепочки сертификатов и имени сервера сохранены.
Компромисс: постквантовый гибридный обмен для этих соединений отключён.
Глобальные переменные окружения, ключи и серверные настройки не меняются.

Установка TCP/TLS/WebSocket ограничена 15 секундами (либо более ранним
deadline вызывающего кода). Уже установленное соединение не ограничивается
этим таймаутом. Это не добавляет постоянную проверку здоровья туннеля.

## Проверки 2026-09-18

- Go 1.25.0, как в предыдущем Android APK: targeted race-тесты TLS и
  WebSocket прошли пять повторений; `go vet ./client/go/outline/...` прошёл.
- `go test -race -timeout=120s
  -skip=TestCheckTCPConnectivityWithHTTP_ValidURLs ./client/go/outline/...`
  прошёл. Полный прогон без skip выявил EOF в существующем тесте внешних
  HTTP-сайтов через текущую сеть Mac; это ограничение проверки, не зелёный
  полный прогон.
- Проверены отмена и deadline установки, зависание TLS и HTTP upgrade,
  закрытие сокета после таймаута, повторное соединение, сохранение
  установленного соединения после отмены dial context, TLS 1.3,
  отклонение недоверенного сертификата и неправильного hostname.
- Отдельный probe на Go 1.25.0 использовал фактические изменённые
  `configregistry` stream/packet WebSocket parsers и Outline Shadowsocks SDK.
  Внешний транспорт привязан к en0 без переключения VPN Mac.
  Hostkey Instagram: 16/16 через 8443 и 16/16 через 443 — HTTPS к трём
  назначениям (в том числе проверка IP выхода), DNS через UDP, четыре раунда.
- Web runner: 85 тестов прошли, exit 0. При этом webpack напечатал ошибку
  разрешения `data:text` в существующей зависимости тестового runner;
  результат не считается полностью чистой проверкой сборки тестов.
  Production web build и Android `assembleRelease` прошли отдельно.
- Пересобрана Go AAR для Android; в arm64 библиотеке конечного APK
  присутствуют `tlscompat.Config` и `boundedWebsocketConnect`.
- APK: `com.vdomike.vpn`, 1.1.8 / 10108; подпись совпадает с публичной
  1.1.7; проверка подписи и `zipalign -c -P 16 4` прошли.

## Ограничение

Физический Android владельца недоступен через adb. Причина его конкретного
сбоя пока не доказана: исправление основано на воспроизводимом сравнении
транспортов. После обновления нужна проверка на Wi-Fi и мобильной сети,
включая продолжительную сессию. Нельзя обещать устранение всех обрывов.
