# VPN для приложений: два режима

- **Без VPN для выбранных** — прежнее поведение: отмеченные приложения идут
  напрямую, остальные используют VPN. Старые настройки не мигрируют и не
  сбрасываются.
- **VPN только для выбранных** — через VPN идут только отмеченные приложения,
  включая новые установки только после явного выбора. Остальные идут напрямую.

У режимов независимые сохранённые списки. При первом открытии нового режима
список пуст: пользователь выбирает несколько приложений с нуля. Пустой список
или список только удалённых приложений не включает VPN для всех: ручное
подключение возвращает пользователя к выбору приложений, а сервис дополнительно
запрещает устанавливать туннель с пустым эффективным allow-list.

Смена режима и галочек сопровождается напоминанием переподключиться. Действующий
туннель не меняется во время редактирования. При следующем подключении новые
правила передаются через AIDL; при изменении правил создаётся новый TUN.
Автозапуск восстанавливает режим и список последнего успешного подключения.
Удалённые приложения остаются в сохранённом списке для повторной установки.

Нативный Android API не допускает одновременного применения allow- и deny-list.
В режиме исключений VPN-клиент исключает собственный пакет; в режиме включений
он никогда не добавляется в разрешённые приложения.

Проверки: `AppRoutingRulesTest` (совместимость старых настроек, независимые списки,
удалённые приложения, пустой выбор, сериализация) и `AppRoutingActivityTest`
(переключатель, выбор, подсказка, accessibility, восстановление экрана).
